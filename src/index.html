material-button

Five MD3 styles via variant. Add disabled to lock and dim.

filled
tonal
elevated
outlined
text
Sample usage 
<material-button variant="filled" label="Save"></material-button>
<material-button variant="outlined" label="Cancel"></material-button>
<material-button variant="text" label="Disabled" disabled></material-button>

material-card

Slotted container in three MD3 surface styles via variant.

Elevated

Sits on a low container surface with a soft shadow.

Filled

Highest container tone — useful for emphasized inline regions.

Outlined

Plain surface with an outline-variant border. Lowest visual weight.

Sample usage 
<material-card variant="elevated">
  <h3>Title</h3>
  <p>Body content via slot</p>
</material-card>
Override the stylesheet path with <meta name="material-stylesheet" content="..." /> — see README.
