@robustarush/material

Material 3 web components — Stencil + Tailwind v4

material-button

Five MD3 styles via variant; sizes XS–XL; form-associated.

material-icon-button

MD3 Expressive icon buttons — variants × sizes × shape × width, toggle.

material-card

Slotted container — elevated / filled / outlined.

material-checkbox

18dp box, 48dp target; states, error, help text; form-associated.

material-radio

20dp ring, 48dp target; material-radio-group coordinates value, ARIA, arrow keys; form-associated.

material-textfield · file-field

MD3 text field — floating label, supporting/error text, icons, file field.

material-textarea

Multi-line MD3 text area — fixed rows or auto-resize between min/max; form-associated.

material-select

MD3 single-select — textfield + chevron trigger that opens a popover menu of material-option children; supports material-optgroup, type-ahead, clearable, form-associated.

material-menu

MD3 vertical menu with leading/trailing slots; popover-anchored, viewport-aware.

material-dialog

MD3 modal — basic / full-screen / adaptive. Native <dialog> + scrim; opens via data-dialog-target, native command, or .show().

material-list

MD3 list — 1/2/3-line items, leading/trailing slots, single & multi selection.

material-navigation-rail

MD3 Expressive nav rail — collapsed (96dp) / expanded (220–360dp), with shared material-navigation-item.

material-app-bar

MD3 Expressive top app bar — small / medium-flexible / large-flexible; collapses to small on scroll.

material-search-app-bar

MD3 Expressive search variant — embedded search container, form-associated, inside/outside icon slots.

material-badge

MD3 badge — small dot or large pill (up to 4 chars). Slots into material-icon-button, material-navigation-item, and any trailing slot.

material-tabs

MD3 tabs — primary / secondary variants, fixed or scrollable, optional icons + badges, anchor or button mode.

material-loading-indicator

MD3 Expressive — spins while morphing through 7 shapes; default / contained variants, 24–240dp.

material-linear-progress

MD3 linear — determinate / indeterminate × flat / wavy, configurable thickness, stop indicator. For long waits (5s+).

material-circular-progress

MD3 circular — determinate / indeterminate × flat / wavy, 24–240dp. For long waits (5s+); use material-loading-indicator for short.

material-calendar

MD3 standalone calendar — 360×456dp grid, single-date selection, month/year picker views, locale-aware via Intl or Django jsi18n.

material-date-field

Text-field + calendar trigger. Opens an adaptive material-dialog with a material-calendar; hidden ISO input for form posts.

material-time-picker

MD3 standalone time picker — dial + input variants, 12/24h, locale-aware via Intl or Django jsi18n.

material-time-field

Text-field + schedule trigger. Opens an adaptive material-dialog with a material-time-picker; hidden ISO HH:MM input for form posts.

material-toolbar

MD3 Expressive docked & floating toolbars. Standard / vibrant color schemes; horizontal / vertical orientation. Layout-only container — caller handles positioning.

material-tooltip

Plain & rich MD3 tooltips. Hover, focus, or long-press; rich variant supports persistent click-to-open with subhead and actions.

material-datetime-field

Text-field + event trigger. Opens an adaptive material-dialog hosting material-calendar and material-time-picker with a footer toggle; hidden ISO YYYY-MM-DDTHH:MM input for form posts.

Override the stylesheet path with <meta name="material-stylesheet" content="..." /> — see README.
