material-toolbar

MD3 Expressive docked & floating toolbars. Layout-only container — caller handles positioning. Standard / vibrant color; horizontal / vertical orientation (floating).

docked / standard
docked / vibrant
floating / horizontal / standard
floating / horizontal / vibrant
floating / vertical
floating + FAB
with textfield
Sample usage 
<!-- docked: full width, square corners; caller positions it (e.g. fixed bottom) -->
<material-toolbar variant="docked" aria-label="Document actions">
  <material-icon-button icon="format_bold" aria-label="Bold"></material-icon-button>
  <material-icon-button icon="format_italic" aria-label="Italic"></material-icon-button>
  <span style="flex:1"></span>
  <material-button variant="filled" icon="check" label="Done"></material-button>
</material-toolbar>

<!-- floating: pill, contextual -->
<material-toolbar variant="floating" color="vibrant">
  <material-icon-button icon="reply" aria-label="Reply"></material-icon-button>
  <material-icon-button icon="archive" aria-label="Archive"></material-icon-button>
  <material-icon-button icon="delete" aria-label="Delete"></material-icon-button>
</material-toolbar>

<!-- vertical floating -->
<material-toolbar variant="floating" orientation="vertical">...</material-toolbar>
